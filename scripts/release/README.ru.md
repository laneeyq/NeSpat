# NeSpat для MacBook с Apple Silicon

Скачайте NeSpat.dmg со страницы Releases, откройте образ и перетащите NeSpat.app на папку Applications. Запустите NeSpat из «Программ». Пройдите шаги системного установщика и подтвердите установку администратором. Панель появится в строке меню. Для первого запуска нужны открытая крышка, разрешённый обычный сон и доступные датчики температуры и питания. От батареи требуется не менее 15% заряда. Установка предназначена для текущего пользователя на загрузочном диске, macOS 14 или новее. Поддержка датчиков зависит от модели.

Это локально подписанный выпуск без нотариализации Apple. macOS может попросить разрешить открытие пакета в «Системные настройки → Конфиденциальность и безопасность». На управляемых компьютерах установка зависит от политики организации.

Выберите длительность или введите минуты и нажмите «Применить». Включите «Не спать», дождитесь ☕ и закройте крышку. ⚠ означает проблему или восстановление. При закрытии крышки приложение запрашивает гашение всех дисплеев. Настройку запроса пароля определяет macOS. «Автоматический режим» запоминает подготовку сессии при запуске, «Запускать при входе» открывает панель после входа пользователя. Остановить сессию можно верхним переключателем.

Рабочее приложение находится в /Library/Application Support/NeSpatPrivileged/NeSpat.app. Установщик сохраняет в защищённом профиле текущий UID, модель, сборку macOS и подписи программ. После смены сборки ОС может потребоваться переустановка. Если установлена прежняя локальная версия, сначала завершите сессию и используйте её штатный деинсталлятор.

При прерывании установки откройте NeSpat из «Программ» повторно. Для удаления завершите сессию, дождитесь обычного сна, выберите «Выход» и выполните в Терминале:

sudo "/Library/Application Support/NeSpatPrivileged/Uninstall" --uninstall

После удаления служб переместите NeSpat из «Программ» в Корзину.
