<h1 align="center">NeSpat</h1>

<p align="center">Закрой крышку MacBook, пока идёт загрузка или сборка проекта.</p>
<p align="center"><strong>macOS 14+ · Apple Silicon · Приложение в строке меню</strong></p>

## Установка

1. Скачай [NeSpat.dmg из последнего релиза](https://github.com/laneeyq/NeSpat/releases/latest/download/NeSpat.dmg).
2. Открой образ и перетащи **NeSpat.app** на папку **Applications** («Программы»).
3. Открой NeSpat из «Программ». При первом запуске подтверди системный запрос администратора для установки служб. В строке меню появится NeSpat.

Подтверждение нужно NeSpat для настройки фоновых служб. У выпуска нет нотариализации Apple, поэтому macOS может запросить дополнительное подтверждение в разделе **«Конфиденциальность и безопасность»**. Доступность температурных датчиков зависит от модели MacBook.

## Первая сессия

Допустим, ты скачиваешь большой файл и хочешь закрыть ноутбук на полчаса. Открой панель NeSpat, введи **30** в поле минут, нажми **«Применить»** и включи **«Не спать»**. Когда в строке меню появится **☕**, крышку можно закрыть. Mac продолжит загрузку, а NeSpat попросит систему погасить подключённые дисплеи.

Пока крышка открыта и сессия активна, NeSpat запоминает расположение и размеры обычных окон на внешних экранах. Для этого нужен «Универсальный доступ» в настройках macOS. При закрытии крышки приложение пытается отключить доступные внешние экраны. При открытии крышки или завершении сессии оно подключает свои дисплеи обратно, ждёт стабилизации раскладки и возвращает доступные окна. Полноэкранные окна и окна на других рабочих столах зависят от поведения macOS и самих приложений.

Для оставшихся подключённых экранов действует резервное гашение при пробуждении и проверка каждые пять секунд. Без доступа к окнам и на неподдерживаемых конфигурациях используется этот же режим. Блокировка внешнего ввода освобождается при открытии крышки или завершении сессии. В резервном режиме движение мыши может кратко зажечь экран.

Таймер идёт с начала сессии. Через полчаса NeSpat вернёт обычный режим сна. Закончить раньше можно тем же переключателем. Для запуска сессии крышка должна быть открыта. При работе от батареи нужно хотя бы 15% заряда.

| В панели | Как работает |
| --- | --- |
| **1 ч · 3 ч · 8 ч** | Готовые варианты длительности. Для другого срока введи минуты вручную. |
| **Без лимита** | Сессия продолжается до ручной остановки или срабатывания защиты. |
| **Заряд устройств** | Раскрой список под батареей MacBook. Для подключённых Bluetooth-устройств показывается доступный macOS процент заряда, для LAMZU Maya X с совместимым 8K-приёмником заряд читается напрямую. Прочерк означает, что устройство не сообщило процент. |
| **Запускать при входе** | Открывает NeSpat при входе в macOS. |

## Что видно в строке меню

**☕** означает, что система подтвердила активную сессию. **⚠** появляется, когда состояние требует внимания, например пока служба проверяет возврат к обычному сну. Открой панель, чтобы увидеть причину.

Цифры рядом показывают температуру чипа, загрузку процессора и занятую память. В панели также видны заряд батареи и источник питания.

Нажми на строку **«Батарея»**, чтобы увидеть циклы, текущий заряд, полную и проектную ёмкость в мА·ч. Процент рядом с ёмкостью показывает отношение полной ёмкости к проектной.

## Обновления

Начиная с 1.1.0, NeSpat проверяет последний стабильный выпуск своего репозитория при запуске и раз в сутки. Когда доступна новая версия, приложение скачивает пакет служб и панели и сверяет его SHA-256 с данными релиза GitHub. Во время сессии кнопка установки недоступна. После её окончания нажми **«Установить»** и подтверди системный установщик. Фоновую проверку можно выключить в панели.

Для перехода с версии 1.0.x заверши сессию, нажми «Выход», скачай новый DMG и замени NeSpat в «Программах». Открой приложение и пройди установку служб один раз.

## Если что-то пошло не так

- **После открытия крышки Mac просит пароль.** Гашение дисплеев и запрос пароля регулируются раздельно. Для разблокировки действуют настройки macOS.
- **Панель закрылась во время сессии.** Сессия продолжится. За восстановлением обычного сна при сбое основной службы следит отдельный watchdog.
- **Установка прервалась.** Запусти тот же пакет ещё раз. Если на Mac уже есть старая локальная версия, заверши её сессию и удали её штатным деинсталлятором.

<details>
<summary><strong>Удаление</strong></summary>

Заверши сессию, дождись статуса «Обычный сон», выбери «Выход» и выполни в Терминале:

```sh
sudo "/Library/Application Support/NeSpatPrivileged/Uninstall" --uninstall
```

После удаления служб перемести NeSpat из «Программ» в Корзину.

</details>

<details>
<summary><strong>Сборка из исходников</strong></summary>

Панель, фоновые службы, установщик и клиент обновлений написаны на Rust. Для сборки DMG на Apple Silicon понадобятся Rust 1.94, инструменты командной строки Xcode и Python с dmgbuild. Проверки текущей реализации выполняет Cargo. Предыдущий комплект Swift и тесты исторических локальных установщиков доступны в [снимке до удаления совместимого стенда](https://github.com/laneeyq/NeSpat/tree/4aa0673f453e4c540c7e2b3170c788932bc7a425).

```sh
bash scripts/test.sh
python3 -m venv .build/dmg-tools
.build/dmg-tools/bin/pip install dmgbuild==1.6.5
PATH="$PWD/.build/dmg-tools/bin:$PATH" bash scripts/release/build.sh "$PWD/dist"
```

Готовый образ появится в `dist/NeSpat.dmg`.

</details>
